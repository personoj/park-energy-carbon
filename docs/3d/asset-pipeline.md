# 3D 资产管线

当前仅有三个程序生成方块；真实模型、漫游、楼层切换、剖切与告警叠加均待实现。

## 模块边界

viewer 输入：场景清单、资产 ID/变换/显示状态、当前选中 ID。输出：selectAsset、相机状态等展示事件。查看器不查询能耗、不核算、不接触数据库。业务页面负责数据获取与详情面板。

当前使用 Three.js/R3F。真实 GIS、地形、大范围倾斜摄影出现时评估 Cesium 适配器，不把经纬度逻辑塞进普通厂房查看器。

## 交付规范

- 模型展示格式 GLB/glTF，源文件留在私有对象存储或专用资产库。
- 统一米制、本地原点、轴向；GIS 需求另存坐标系和变换矩阵。
- 园区外壳、厂房内部、设备按加载层级分包。
- 构件标识需要跨导出保持稳定；`modelVersion + componentKey → assetId` 显式映射，不依赖节点下标。
- 一台设备可对应多个 mesh；点选范围可用代理几何体，外观合并不能破坏业务拾取。
- 更新模型同时校验映射缺失、重复、悬空资产和单位变化。
- 在目标电脑与目标分辨率测首屏时间、GPU 显存、帧率和拾取延迟后确定预算；不预先承诺固定帧率。

生产资产优先采用贴图压缩、实例化、细节层级和烘焙光照。WebGL 不可用时保留资产列表和业务查询；该降级能力在真实模型阶段实现。
