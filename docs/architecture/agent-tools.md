# Agent、SQL 与受控写入

状态：已确认能力范围，尚未实现网关/数据库权限/模型接入。没有任何可运行任意 SQL 的公开端点。

## 能力与端口

| 工具 | 作用 | 写入方式 |
|---|---|---|
| describe_datasets | 查询授权数据目录、字段、单位 | 无 |
| query_data | 在授权视图上执行受限 SELECT | 无 |
| prepare_import | 解析数据、建议结构化转换计划 | 导入暂存区 |
| validate_import / preview_import | 校验和展示差异 | 保存校验与预览记录 |
| commit_import | 提交已校验、绑定版本的导入批次 | 调用导入用例与领域接收接口 |
| run_accounting | 使用指定方法/因子/数据快照计算 | 确定性核算服务 |
| save_accounting_draft | 保存草稿与证据链 | 核算用例限定字段 |

用户身份/园区范围由服务端注入，工具参数中的 actorId/parkId 不可扩大权限。工具接口与模型供应商解耦；对话入口和未来 MCP 入口都调用同一工具应用层。

## SQL 查询网关

1. 使用独立非属主、非超级用户、无 BYPASSRLS 的查询角色，只授予授权视图所需的 SELECT。
2. 查询在只读事务内运行，限制 statement/lock 超时、行数、返回字节、并发与取消。
3. PostgreSQL AST 校验单语句、允许的语法/关系/函数；拒绝 DDL/DML、COPY、CALL、锁定、写 CTE、外部访问与危险函数。不能只靠正则或 SELECT 前缀。
4. 只读权限不是完整隔离：函数调用和资源消耗仍需限制；审计记录拒绝原因。
5. 园区授权通过数据库策略/受控视图和服务端上下文执行，不由模型拼 WHERE 实现。视图权限与 RLS 实际效果必须测试。
6. 查询结果带字段、单位、期间、数据版本、质量提示、截断状态和 queryId，Agent 解释须引用可追溯结果。

## 写入与核算

Agent 可以导入数据，但不拥有任意写 SQL 的能力。导入、草稿、数据修订使用不同的应用用例和数据库最小权限。核算结果由确定性引擎计算；Agent 负责选工具、解释和建议，不以自然语言替代可复现公式。

commit_import 必须绑定已验证计划、预览版本和幂等键；允许已授权的自动导入策略，不能把“每次必须人工确认”写成未经用户确认的永久产品限制。权限不足或存在无法消除的映射歧义时返回明确阻塞原因。

## 审计与供应商适配

记录 runId、操作者、园区、工具版本、计划版本、输入摘要、数据引用、SQL 摘要/受保护正文、结果摘要、耗时、状态与错误码。对话和数据保留周期待确认；凭据、完整原文件和敏感查询结果不写公开日志。

LLM provider port 定义消息、工具调用、取消、超时与用量；业务代码不导入具体模型 SDK。发给供应商的数据范围需配置，默认不传数据库凭据和无关原始文件。

必须验证：提示注入不能扩大权限；查询不可跨园区；SELECT 调用危险函数被拒绝；导入重试不会重复写入；模型故障不会把未完成工作标为成功。
