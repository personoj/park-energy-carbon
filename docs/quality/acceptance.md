## 业务阶段必测

| 领域 | 核心行为 |
|---|---|
| 导入 | 重复文件/跨文件重复、冲突、单位时区错误、错误行、事务回滚、重试、权限 |
| 计量 | 累计表复位、换表、倍率变化、总分表去重、缺测不等于零 |
| 新能源 | 储能损耗、能源流平衡、购售电分离、权益重复使用 |
| 核算 | 同快照可复算、因子适用期、单位/GWP、版本更正、发布权限 |
| Agent | 越权 SQL、危险函数、写 CTE、超时/截断、提示注入、导入幂等 |
| 3D | 构件映射、模型更新、点选、降级、目标 GPU 性能 |

上述业务测试随实现添加，当前骨架通过不能证明这些能力已经存在。
