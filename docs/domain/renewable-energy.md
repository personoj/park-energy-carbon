# 新能源与能源流

状态：概念设计，现场类型和计量点待确认。

分别记录：购电、光伏/其他发电、自发自用、上网电量、储能充电、储能放电、终端负荷及损耗。禁止只保存一个“净用电”字段后用于所有统计。

在一致时间区间和计量边界下，示意平衡为：

`购电 + 发电 + 储能放电 = 终端负荷 + 储能充电 + 上网 + 损耗 + 未平衡量`

这是能源流检查模型，不是通用碳核算公式。实际测点位置、变压器损耗和重复计量必须先确定；未平衡量应显示，不能自动补成零。

## 储能

- 记录充电来源、放电去向、SOC、效率、损耗与时间区间。
- 储能不是新的零碳发电来源。是否追踪充电来源、采用哪种碳分摊和损耗方法，需要版本化决定。
- 避免同一份电力在购入、充入和放出各计一次排放。
- 峰谷套利、削峰量、减排情景与正式组织排放分别报告。

## 绿电与环境权益

独立管理合同/凭证、持有人、适用电量、期间、地区、使用/注销状态和证据。电量流转不自动等于环境权益转移；上网电量不自动抵扣园区排放，避免凭证重复使用。

后续扩展风电、冷热联供、热泵、充电设施时，复用能源载体、流向和设备能力，不在核心核算流程中增加设备型号分支。
