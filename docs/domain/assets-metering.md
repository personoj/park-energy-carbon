# 资产与计量

资产层级：组织 → 园区 → 建筑/区域 → 设备。设备的能源能力（发电、储能、消费、转换）可组合；3D 构件不是业务主键。

测点单独建模：`pointId, assetId, quantity, unit, direction, samplingMode, timezone, validFrom, validTo`。测点归属与倍率变更保留历史。资产与构件允许一对多，测点与资产通过有效期映射。

## 读数语义

- 功率 kW 与电量 kWh 不互换；累计表读数与区间电量分开。
- 累计电表差值必须处理复位、换表、回绕与缺测，不能把负差值直接当回馈电量。
- 记录事件时间、接收时间、区间结束、时区、源单位、标准单位、倍率和质量码。
- 原始记录不可静默覆盖；修订记录引用被替代版本。
- 缺失值不等于零；估算/分摊值独立标注方法与证据。
- 防止总表和分表叠加重复统计；计量拓扑与组织归属是不同关系。

告警关联资产/测点与规则版本，具有发生、确认、关闭时间和操作者。告警不直接改写核算活动数据。
