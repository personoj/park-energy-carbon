# 里程碑

| 阶段 | 交付 | 验收 |
|---|---|---|
| M0 初始化 | 文档、工作区、3D 占位、演示 API、CI、公开仓库规则 | 安装/类型检查/构建通过；合成资产可选择；无真实数据 |
| M1 数据基础 | 身份与授权、资产/测点、PostgreSQL 迁移、OpenAPI | 不同园区隔离；计量映射有生效期；契约可生成客户端 |
| M2 导入闭环 | 文件解析、映射、校验、预览、批次提交 | 重复导入不重复记账；单位/时区错误可见；失败可追溯 |
| M3 能源与核算 | 能源流、版本化因子/方法、核算草稿、发布流程 | 已知样例可复算；缺失数据阻止发布；同输入同结果 |
| M4 Agent 接入 | 受限查询、导入和核算工具 | 越权/写 SQL 被拒绝；工具调用具备身份和审计；导入与人工走同一服务 |
| M5 真实 3D 与告警 | 模型管线、资产映射、状态叠加、告警流转 | 更新模型仍可定位；跨厂房按需加载；目标设备性能达标 |

3D 资产制作可以提前，与 M1—M4 并行开展人工协作。完整导入与核算能力不依赖最终模型交付。此表不是日期承诺；测点规模与人员确认后再估工期。
